**WSword PS5 - milestone 4, fix 14: your own controller picture on the Controls screen.**

WSword can now load a `controls` folder from the title's folder (`/data/homebrew/PPSA99777/controls/`). It changes only the pause menu's **System > Controls** screen (the Basic Controls, horse and Sand Seal pages):

- `front.png`: the controller from the front, 576x288, greyscale with transparency
- `top.png`: the shoulder buttons from above, 576x100
- `PaAllControllerTipsNN_00.bflyt`: that screen's layout, with the labels' lines leading to the buttons in your picture

The game's pictures and layout are replaced only on that screen. Everything else (HUD, fonts, other menus) stays as it is. Delete the folder to go back to the game's own.

The log confirms it: `[fs] controls screen: the player's layout ...` at startup, and `[controls] controls/front.png ...` when the screen opens.

Also included: fix 13's 4K support and the earlier HUD and frame-generation fixes.
