## WSword PS5 0.3.28-m4

### amiibo: tapping a figure now works

- **The fix:** in 0.3.26 / 0.3.27 / slate.19, picking a figure in the amiibo bar did nothing.
  - The game closes its amiibo event after each use of the rune, and WSword handed the same closed event back the next time, so the game never heard the tap.
  - Each use now gets a fresh one, as on the Switch, so the game finds the figure and drops its items.
- **If a tap still does nothing:** the log now records the game's amiibo calls, so send it in.

### The amiibo bar, made like the game's own selectors

The bar is now built like the weapon, bow, shield and rune bars, in the same place, at the same size.
- **Slots:** translucent dark square slots on a faint band.
- **Name:** in italics above, with a dotted rule.
- **Selection:** the chosen slot gets white corner brackets that spring onto it as you move.
- **Stick mark:** the right stick's R underneath.
- **Each slot:**
  - a figure on its stand in its series' colour (a card for the cards);
  - the figure's initials in the game's black count badge;
  - a gold star for favourites.
- **Motion like the game's:**
  - the bar eases in;
  - the row glides;
  - the old name fades under the new one;
  - after a tap, the chosen slot lights up as the bar fades away.
- **Sounds:** a soft click each step, a lighter one for a new series, a rising (or falling) pair for a favourite, a chime for the tap, and a breath of air as the bar opens. They're made by WSword, not copied from the game, and follow the game's volume.
- **Prompts:** smaller, in white over the game, as the game's own prompts are.
- **No Nintendo artwork:** there are no amiibo pictures, so each slot draws its own figure.

Install as before: replace the PPSA99777 folder's files with this zip's.
