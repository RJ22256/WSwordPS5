## WSword PS5 0.3.26-m4

**amiibo: every figure, from an amiibo bar in the game.**

Use the amiibo rune as you would with a real figure. A bar of every amiibo comes up across the middle of the screen, in the look of the game's weapon and rune bars. Pick a figure and tap it, and the game drops its items as if you had touched a real one to the controller.

### The amiibo bar's controls
| Button | What it does |
|---|---|
| R stick / d-pad left and right | The next figure. Hold it to go faster. |
| d-pad down / up | The next / previous series |
| Cross | Tap the figure |
| Square | Favourite on or off. Favourites come first in the bar. |
| Circle | Cancel. This is the game's own cancel: it leaves the amiibo rune. |

### What's in the bar
- **The order:** your favourites, then Breath of the Wild's own figures (Wolf Link, the Archer and Rider Links, Zelda, the Guardian, the Bokoblin, the four Champions), then the rest of the Zelda series, then every other amiibo by series, with cards last.
- **What it knows about each figure:** the bar has all 932 amiibo. For each it uses only the public id that says which character it is and its name (from AmiiboAPI's list). No figure dump or Nintendo keys are used.
- **Saved data:** what the game writes to a figure, such as Wolf Link's hearts, is kept in the `amiibo` folder in WSword's data. It's there again the next time you tap that figure.

### Once a day
- **The game's own rule is that each figure works once a day.** The game counts each figure by its serial number.
- **Seeing which figures you've used:** a figure you've already tapped today shows amber corner brackets and a clock. You can still pick it, but the game itself will refuse it.
- **To turn the limit off:** go to Settings → Controls → amiibo → **One scan a day per figure**. With it off, every tap gives the figure a new serial number, so the game treats each tap as a new figure.
- **Clearing favourites:** the same section has **Clear favourites**.

### Also
The game's own **amiibo** option (Options → Gameplay) is back. It's the game's switch for the amiibo rune, so it must be on.

Install as before: replace the PPSA99777 folder's files with this zip's.
