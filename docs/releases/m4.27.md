## WSword PS5 0.3.27-m4

**amiibo: no daily limit.**

- **Tap any figure as often as you like.** The game's once-a-day rule is now off by default: every tap gives the figure a new serial number, so the game treats it as a figure it hasn't seen today. Wolf Link and every other figure keep their saved data as before.
- **Your setting from 0.3.26 isn't carried over**, so the limit is off for everyone after updating.
- **To have the game's rule back:** Settings → Controls → amiibo → **One scan a day per figure** → on. With it on, figures you've used today show amber corner brackets and a clock again.

Everything else is as in 0.3.26-m4.

Install as before: replace the PPSA99777 folder's files with this zip's.

Made without testing in the game.
