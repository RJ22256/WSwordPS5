**WSword PS5 - milestone 4, fix 5: Lossless Scaling frame generation.**

How to use it:

1. Copy your own `Lossless.dll` (from Lossless Scaling, on Steam) to `/data/homebrew/PPSA99777/lsfg/Lossless.dll` over FTP. The folder is already there, with a note.
2. In WSword's menu (touch pad + OPTIONS) > Display > Frame generation, choose **Lossless 2x**. **AMD FSR 3** is there too and needs no file.

What it does:

- **Quality mode:** the game draws 30 frames a second, and frame generation adds one between each two, so 60 reach the screen. Choosing it switches Quality's frame limit to 60 on screen by itself.
- **Performance mode:** it changes nothing you'd see. The game already runs at 60, and the TV's 60 Hz is the most the console shows, so 2x is the only multiplier offered.
- The menus, the map and the FPS counter are never generated. The first start with Lossless builds its shaders from the DLL, which takes a moment. After that they're kept in `lsfg/`.
