**WSword PS5 - milestone 4: the game code on the console.** WSword for the PS5 now loads the game code that WSword Configuration's **Export for PS5** builds on your PC from your own game files. This is the first build that can try to start the game itself.

1. Update WSword on your PC to **0.3.21-pc.1** (it has the export). Open **WSword Configuration** > Game files > **Export for PS5** and wait for "PS5 export done".
2. Delete `/data/homebrew/PPSA99777/` on the console. Unzip `WSwordPS5-PPSA99777.zip` and copy `PPSA99777` there over FTP.
3. Then copy these from your WSword folder into `/data/homebrew/PPSA99777/` (beside `eboot.bin`):
   - `PS5/swgame.so` and `PS5/swgame.so.id`
   - the whole `extracted` folder (your game files; large, so it takes a while)
4. Start **WSword**. Send `/data/homebrew/PPSA99777/WSword.log` back, plus a photo of the screen.

What's new:
- An in-process loader for the game code. A title can't load libraries itself, so WSword puts the code into executable direct memory, applies its relocations, and binds its imports by name. Those imports are 1,900 of WSword's own functions plus the C library functions the game code's headers declare.
- The console and the PC export compute the same game code id. A `swgame.so` built by another WSword version isn't loaded; the log says so instead.

Expect problems: this is the first time the game itself runs on the console.
