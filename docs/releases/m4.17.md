**WSword PS5 - milestone 4, fix 17: the warp, the buttons with mods, and a PS5 keyboard.**

- **The warp effect is smooth again.** When Link teleported, his model broke up into big blocks instead of dissolving. The game draws its dissolve noise into a compressed 3D texture one slice at a time, which WSword couldn't do, so the noise stayed empty. WSword now draws into it slice by slice.
- **The ✕ ○ □ △ buttons now show with mods too.** A mod that brings its own `Pack/Bootup.pack` (armour mods often do) used to stop WSword's PS5 button letters and the button-diamond swap. Those changes are now made on the mod's pack. A mod's own `ResourceSizeTable` also gets WSword's size entries now.
- **The text keyboard looks like the PS5's.** It's used for naming a horse and similar screens:
  - a dark rounded panel with a text box and blinking cursor
  - a white highlight on the focused key and a blue Done key
  - PS5 controls: ✕ type, □ delete, △ space, L2 caps, R2 or OPTIONS done, ○ close
- **Light bar:** if WSword can't read Link's hearts, the light bar now stays blue instead of guessing.

Also included: the HDR look (fix 16) and the DualSense features (fix 15).
