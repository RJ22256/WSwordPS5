**WSword PS5 - milestone 4, fix 9: the game's threads get CPU cores of their own, and the log shows where each frame's time goes.**

- **Dedicated cores.** The game's four CPU cores now each run on a physical PS5 core of their own, and all of WSword's helper threads (graphics recording, shader work, audio) share the cores left over. Before, the console could put a busy helper on the same core as the game's main thread, and the main thread's speed is what sets the frame rate. Expect steadier frame times, and a few percent more in busy areas.
- **Where the time goes.** Every 10 seconds the log now has a `[threads]` line showing the busiest game threads. For each one it gives the share of time spent running game code, in WSword's graphics backend and waiting for its core, plus how busy the graphics recording thread is. Play somewhere busy (a town, or a fight) for a minute and send the log. It shows which part to speed up next.
- The log's `[cpu]` line at the start shows the placement it chose.

If anything gets worse, turn the core placement off by creating an empty file named `WSword-no-pin` next to `WSword.log` (in the title's folder) over FTP, then restart.
