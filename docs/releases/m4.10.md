**WSword PS5 - milestone 4, fix 10: frame generation no longer halves the game's frame rate.**

Your log showed the cause. The game ran at about 67 fps without frame generation, but with Lossless on it dropped to about 36 (36 game frames plus 36 generated is the ~72 you saw). Changing the flow scale made no difference, so Lossless's own GPU work wasn't the problem.

The PS5 has one graphics queue, so frame generation's presents ran on the game's own thread. There, each present waited for the GPU to finish the frame, then slept another half frame to space the pair. The game spent most of every frame waiting.

That wait is gone. At 120 Hz the console shows the generated frame and the game's frame one refresh each, in order, so it spaces them by itself. **Performance with frame generation should now hold 60 game frames shown as 120.** This applies to both Lossless 2x and AMD FSR 3.

Also in this build (from fix 9): the game's threads run on dedicated CPU cores, and the log has a `[threads]` line every 10 seconds.

A tip: Lossless works on the finished picture, HUD included, so the hearts and icons can smear when you move. AMD FSR 3 generates frames without the HUD and avoids that.
