**WSword PS5 - milestone 1: the console check.** Not the game yet: a WSword title for a jailbroken PS5 that boots, draws on the GPU, and checks what the port needs on your console.

1. Unzip `WSwordPS5-PPSA99777.zip` and copy `PPSA99777` to `/data/homebrew/PPSA99777/` over FTP.
2. With ShadowMountPlus loaded, **WSword** appears on the home screen: start it.
3. OPTIONS or the touch pad shows its window: **WSword PS5 - console check**, with what's missing.
4. Send `/data/homebrew/PPSA99777/wsword-check.txt` back.

Built with mihawk-99's PS5_Vulkan (RADV) and PS5 Vulkan Template, and the PS5 payload SDK. No game files or game code inside.
