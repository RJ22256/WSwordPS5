**WSword PS5 - milestone 4, fix 24: a new in-game menu, opened with a two-finger tap on the touch pad.**

- **New bind.** Tap the touch pad with two fingers (rest them together without clicking, then lift) to open or close WSword's menu. The game never reads touches, so nothing in it reacts. The old touch pad + OPTIONS combo no longer opens the menu, because those buttons are also the game's own Minus and Plus.
- **Quick menu first.** A black sheet rises from the bottom over the dimmed game, its tiles arriving one after another: Resume, Mode (Performance / Quality), Ray-Tracing, Frame generation and Performance overlay. A white ring glides to the tile you're on. Circle closes it, and it sinks away as it goes.
- **All settings.** Every option from the previous menu, in categories down the left: Video, Colour, Audio, Controls, Language, Mods and Quit. Switch categories with L1 / R1 (a bar glides to the open one). The rows ease in one after another, the selected row's highlight fades in, switches slide, sliders and values move to their new state, and the selected row's description shows along the bottom. Circle goes back to the quick menu.
- **SST.** The menu uses the PS5's SST typeface if it finds it: copy `SSTRg.TTF`, `SSTMedium.TTF` and `SSTLight.TTF` into a `fonts` folder in the title's folder over FTP. Without it the menu uses Inter. The log's `[menu] SST:` line says which it found.

If anything misbehaves, send `WSword.log`.
