## WSword PS5 0.3.25-m4

**Fixed: switching categories in All settings crashed WSword.**
The new rows kept their animation state through pointers into ImGui's storage. When a category's rows appeared for the first time, the storage grew and moved, and the rows wrote into freed memory. The allocator then stopped the game (signal 6 in `menu_render`). The rows now read and write that state by value.

**The performance overlay now matches the menu.**
- A black card with a thin grey edge, the SST font, grey labels and white values. It fades in when you turn it on or change its mode.
- FPS mode shows the frame rate large, with "FPS" and the frame time beside it in grey.
- Full mode keeps every reading, now in greys and white instead of the coloured labels.

Install as before: replace the PPSA99777 folder's files with this zip's.
