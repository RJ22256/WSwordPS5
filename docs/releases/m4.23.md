**WSword PS5 - milestone 4, fix 23: real HDR, and FSR 1 back as a choice.**

**Real HDR10 output**
- WSword can now send a real HDR10 picture to the TV. The PS5's graphics driver offers HDR to a title that declares it, and WSword now does.
- **Display > HDR:**
  - **Automatic** (the default): HDR whenever the PS5 sends HDR to your TV. That's Settings > Screen and Video > Video Output > HDR set to "On When Supported", on an HDR TV.
  - **On:** always HDR.
  - **Off:** always SDR.
  - Changes take effect at once.
- **HDR highlights:** how bright the brightest things get, such as the sun, sky, fire, lightning and glints. The default is 800 nits. Set it near your TV's peak brightness.
- **HDR paper white:** how bright white things like the menus and HUD are. The default is 200 nits.
- With real HDR on, the **HDR look** colour grade (made for SDR TVs) is usually best turned off.
- WSword.log shows what happened, in lines starting `[ps5] HDR:`, `wsi/videoout:` and `[vk] HDR10 output`. If HDR doesn't come on, install the title again so the PS5 reads its new settings.

**Upscaler**
- **AMD FSR 1 is back** under Video > Rendering > Upscaler, next to AMD FSR 3.1. The modes still use FSR 3. If you pick FSR 1, it stays chosen when WSword starts again.
