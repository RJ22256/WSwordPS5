**WSword PS5 - milestone 4, fix 4: Quality at 1440p, and WSword's own artwork on the home screen.**

- **Quality:** 30 fps with the game drawn at **1440p**. It has Ray-Tracing, **High** draw distance and the sharpest shadow maps. Extreme+ draw distance was buggy on the console, so Quality no longer uses it.
- **Performance:** 60 fps with the game drawn at **1080p**.
- **Output:** WSword now sends the TV its highest resolution, up to 4K. AMD FSR 3 scales each mode's picture up to that: ×1.5 from 1440p, ×2 from 1080p. Where FSR 3 can't run, FSR 1 does it instead.
- **On a 1080p output:** both modes are drawn at 1080p. For 4K, set the PS5's Video Output resolution to Automatic or 2160p.
- **Home screen:** WSword's sword artwork is now its icon and its background, both when it's selected and while it starts. The PS5 shows a homebrew title's background as a still picture, so it uses a frame from the videos.

The log lists every mode the TV offers (`[ps5] display mode`) and what each WSword mode draws at (`[mode]`).
