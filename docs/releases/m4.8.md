**WSword PS5 - milestone 4, fix 8: 1440p back, a console-style menu, and frame generation fixed at 120.**

- **1440p for both modes.** WSword now asks the TV for 1440p (at 120 Hz where the TV takes it) and draws the game at native 1440p in Performance and Quality alike. On a 1080p TV, the game draws at 1080p. On a 4K TV, the TV scales 1440p up itself.
- **Frame generation reaches 120 again.** Your log showed why it stopped near 70. WSword read the console's refresh rate *before* the 120 Hz mode was chosen, saw 60 Hz, and capped the frames on screen at 60. It now reads the rate after the mode is set, so Performance with frame generation shows 60 game frames as 120.
- **Lossless is lighter on the GPU.** At its default flow scale, Lossless's passes took the time the game needed, and the game fell from 60 to about 38 with it on (38 doubled is the "70" you saw). Automatic now finds motion at about 540 lines: 50% at 1080p, 40% at 1440p. If Lossless still pulls the game below 60, try **AMD FSR 3** frame generation, which costs less.
- **A console-style menu.** Touch pad + OPTIONS opens a full-screen menu. Switch tabs with L1/R1, choose with Cross and back out with Circle, and button prompts sit along the bottom. PC-only options are hidden: window size, VSync, HDR, upscaler, ReShade and mouse.

**Why the CPU and GPU show only 30–35%.** The game runs its logic on one thread, and on the PS5's CPU that thread tops out at about 65–70 frames a second. The CPU figure averages all 13 cores, so one busy core reads as a low total. The GPU waits on that thread, so it has headroom. That headroom is what pays for 1440p.
