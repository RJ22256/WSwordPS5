**WSword PS5 - milestone 4, fix 21: AMD FSR 3.1 upscaling and the PS5's own keyboard.**

- **AMD FSR 3.1 replaces FSR 1.** Wherever the game is scaled up (4K, and the "from 1080p" choices under Video > Resolution), the modes now use AMD's temporal upscaler, FSR 3.1. It gives a much sharper, steadier picture than FSR 1, and it also anti-aliases the scene. The motion vectors it needs were already being made for frame generation, so the extra cost is small. If you've set your own options (Mode shows Custom), choose FSR 3 under Video > Upscaler.
  - FSR 4 can't run on the PS5: it needs the machine-learning hardware of AMD's newest graphics cards, which the PS5's GPU doesn't have. FSR 3.1 is the newest AMD upscaler for it.
- **The PS5's own keyboard.** Naming a horse and the other text boxes now open the console's system keyboard, the same one the PS5 uses everywhere. If the console won't give it to WSword, WSword's own PS5-style keyboard comes up instead, and WSword.log says why (`[ime]`).

Also included: everything in fix 20.
