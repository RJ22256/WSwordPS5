**WSword PS5 - milestone 3: WSword itself on the console.** The eboot is now the real WSword runtime (0.3.20-pc.1's sources) built for the PS5, not a check program. It can't play the game yet: the game code and your game files come with the PS5 export in milestone 4. This build starts WSword's start screen on the TV, so we can check the screen, the controller and the logs.

1. Delete the old `/data/homebrew/PPSA99777/` (it is milestone 1's), unzip `WSwordPS5-PPSA99777.zip` and copy `PPSA99777` to `/data/homebrew/PPSA99777/` over FTP.
2. Start **WSword** from the home screen.
3. You should get WSword's start screen (Glass Slate 2) on the TV. Move around it with the D-pad and sticks, Cross to choose, Circle to go back. Its setup can't find game files on the console yet, so it stops there.
4. Close it from the home screen. Then send `/data/homebrew/PPSA99777/WSword.log` back, plus a photo of the screen if anything looks wrong.

What's in it:
- The runtime is cross-built with the PS5 SDK into one archive. It uses FFmpeg 9.0.2 (LGPL), shaderc 2026.3 and zlib, all built for the console, plus RADV.
- A PS5 host layer: game memory comes from direct memory, the log goes to `WSword.log` in the title folder, and the title closes through the system so the console doesn't report a crash.
- SDL3 on the console's own services:
  - Display: the TV through VK_KHR_display, 1080p by default.
  - Controller: DualSense buttons, sticks and triggers, plus motion and rumble. The touch pad click is Back, so touch pad + OPTIONS opens WSword's menu.
  - Audio: 48 kHz output.
- Fonts, WSword's artwork and colour LUTs are included in the folder, laid out like the Windows folder.

Built with mihawk-99's PS5_Vulkan (RADV), the PS5 Vulkan Template and the PS5 payload SDK. No game files or game code inside.
