**WSword PS5 - milestone 4, fix 22: FSR 1 gone, and the Upscaler settings are back.**

- **AMD FSR 1 is removed on the PS5.** AMD FSR 3.1 is now the console's only upscaler: in the modes, the Resolution choices, the menus and the game's own Options screen. A saved setting that used FSR 1 now uses FSR 3.
- **Video > Rendering > Upscaler is back.** It shows **Off** or **AMD FSR 3**, plus **Upscaler mode** (Ultra Quality 1.3x to Ultra Performance 3x) with the size the game renders at.
  - Video > Resolution still sets these each time WSword starts. A change here lasts until then.

Also included: everything in fix 21 (FSR 3.1 in the modes, the PS5's own keyboard).
